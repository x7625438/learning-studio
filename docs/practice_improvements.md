# 主动回忆训练改进说明

## 修复的问题

### 1. 根号符号显示不全
**问题**：数学公式中的根号等符号无法完整显示

**解决方案**：
- 前端 `MathText` 组件增加对块级公式 `$$...$$` 的支持
- 现在支持行内公式 `$...$` 和块级公式 `$$...$$` 两种格式
- 文件：`frontend/src/pages/Practice.tsx:202-216`

### 2. 生成速度慢
**问题**：AI 生成题目时超时时间过短（18秒），导致生成失败

**解决方案**：
- 后端单题生成超时从 18秒 延长到 45秒
- 前端请求超时从 90秒 延长到 120秒
- 文件：`backend/services/learning_service.py:703`

### 3. 题目数量不足
**问题**：用户设置5道题，但只生成2道题

**原因**：薄弱点去重后数量不足，且没有循环复用机制

**解决方案**：
- 查询薄弱点数量从 20 提升到 100
- 当去重后薄弱点不足时，循环复用薄弱点以达到目标数量
- 文件：`backend/blueprints/practice.py:86-147`

### 4. 移除写死的题库
**问题**：使用硬编码的 fallback 题库（一次函数、二次根式等）

**解决方案**：
- 完全移除 `fallback_practice_question()` 函数
- 所有题目由 AI 根据用户真实薄弱点动态生成
- 生成失败时抛出明确错误，而不是使用通用题目
- 文件：`backend/services/learning_service.py`

## 技术架构确认

### 薄弱点来源（动态，非写死）
- 从用户的问答、教材、论文等学习行为中提取
- 通过 `log_interaction()` 和 `analyze_learning_interaction()` 自动识别
- 识别关键词："不会"、"不懂"、"错了"、"答错"等
- 存储在 `weak_points` 表，包含 mastery_score（0-100）

### 题目生成流程
1. 查询 mastery_score 最低的薄弱点
2. 去重（同一知识点只出一次）
3. 如果薄弱点不足，循环复用
4. 并发调用 AI（5个线程）生成题目
5. 每道题包含：题干、4个选项、正确答案、提示、解析
6. 支持 LaTeX 数学公式渲染

### 答题反馈机制
- 答对：mastery_score +18，下次复习间隔 3天
- 答错：mastery_score -24，下次复习间隔 1天
- 分数范围 0-100，低分优先出题
- 使用间隔重复算法（Spaced Repetition）

## 用户体验改进

1. **题目数量**：完全由用户输入决定（1-50题）
2. **生成速度**：更长的超时时间，减少生成失败
3. **数学公式**：完整支持 LaTeX 行内和块级公式
4. **错误提示**：显示详细的错误信息，帮助用户理解问题
5. **真实性**：所有题目基于用户真实学习记录，不使用通用题库
