## ⚠️ 重要：技术基础设施（必须先做）

以下两项工作是一切功能的底层依赖，**必须在所有功能开发之前完成**：

### 1. ChromaDB 向量数据库引入

- **用途**：存储用户交互的向量嵌入，支持语义检索（「你之前问过类似的」）
- **安装**：`pip install chromadb`
- **位置**：`backend/vector_store/`
- **影响**：P0-1 学习档案、P0-2 薄弱点引擎、P0-3 即时问答均依赖此服务

### 2. Flask-SocketIO + APScheduler 引入

- **用途**：WebSocket 实时推送（档案更新、情绪干预、复习提醒）；APScheduler 定时任务（间隔重复提醒）
- **安装**：`pip install flask-socketio apscheduler`
- **位置**：`backend/scheduler/`
- **影响**：P0-1 档案实时刷新、P0-2 复习提醒、P1-2 主动回忆提醒、P2-3 情绪干预推送

### P0-1：学习档案（Learning Profile）

#### 解决的问题

AI 每次对话都是孤立的，用户换一个功能就像换了网站。档案让 AI 记住用户是谁、问过什么、薄弱点在哪里，实现真正的个性化。

#### 什么是档案

用户的学习档案是一份持续积累的记录，包含：

- **基本信息**：学习目标、年级/阶段、偏好学科
- **薄弱点列表**：从交互中自动提取的知识点及其掌握度
- **学习历史**：读过的书/论文、做过的练习、问过的问题
- **行为模式**：常在什么时间段学习、哪个学科投入最多
- **当前状态**：今日学习时长、本周进度、最近卡点

**入口**：侧边栏有一个「学习档案」图标，点击展开档案面板。

1. **自动积累**：用户每次提问、每道练习、每次阅读，都自动写入档案，无需用户操作

### P0-2：薄弱点引擎（Weak Point Engine）

#### 解决的问题

用户做了大量题目，但同类错误一犯再犯。薄弱点引擎自动追踪、分析、提醒，让「无效重复」变成「精准练习」。

#### 什么是薄弱点

一个薄弱点 = 一个知识节点（如「泰勒展开」）+ 掌握度分数（0-100）+ 遗忘曲线数据 + 复习计划。

档案中的每个薄弱点由 AI 自动从交互日志中提取，不需要用户手动标注。

#### 薄弱点来源

1. **答题错误**：用户做错一道题 → AI 解析出知识点 → 标记为薄弱点
2. **提问行为**：用户反复问同一类问题 → 提取为薄弱点
3. **阅读困惑**：用户在同一段落反复提问 → 该知识点标记为薄弱
4. **主动标记**：用户可以手动将某知识点标记为「需要加强」

#### 薄弱点如何更新

- 用户答对 → 掌握度 +15~25%（根据间隔时间调整）
- 用户答错 → 掌握度 -20~30%
- 长期不复习 → 掌握度按遗忘曲线自然衰减

#### 交互环节

1. **自动提取**：每次交互后，AI 自动提取知识点写入薄弱点库
2. **查看详情**：点击薄弱点 → 查看历史相关问题 + 知识点解析
3. **一键练习**：点击「立即练习」→ AI 生成专属练习题 → 提交 → 实时判断对错 → 更新掌握度
4. **忽略**：用户可手动将某个薄弱点标记为「已掌握」（AI 会验证）
5. **复习提醒**：根据遗忘曲线，在最优时间 WebSocket 推送提醒

#### 验收标准

- [ ] 用户答对练习题后，该知识点掌握度上升（可量化）
- [ ] 复习提醒在遗忘曲线的最优时间点触发
- [ ] 薄弱点列表按优先级排序（高优先级的在上面）
- [ ] 点击薄弱点能看到相关的历史提问记录

### P0-3：即时问答（智能追问链）

#### 解决的问题

用户问一个问题，AI 直接给答案——这是搜索，不是学习。智能追问链让 AI 在给出答案前，先引导用户思考，建立完整的解题思路。

#### 设计理念

「授人以鱼不如授人以渔」——但大多数 AI 直接给鱼。追问链是：先问用户「你知道这类题的思路吗」，根据回答决定从哪里开始讲。

#### UI 描述

```
┌─────────────────────────────────────────────────────────┐
│  💬 即时问答                                    [档案]   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  👤 用户                                          │   │
│  │  这道极限题怎么做：lim(x→0) sin(x)/x              │   │
```

### P1-2：主动回忆训练（Spaced Repetition Practice）

#### 解决的问题

学了很多，但忘得更快。主动回忆训练基于间隔重复（Spaced Repetition）算法，在最优时间安排复习，让记忆真正持久。

#### 设计原理

SM-2 算法（SuperMemo 2）变体：

- 用户答题 → 记录「记得/模糊/忘记」
- 根据上次间隔和本次表现，计算下次复习时间
- 遗忘曲线陡峭时频繁复习，随着掌握度提升，间隔拉长

复习间隔示例：

| 掌握度 | 首次答对 | 二次答对 | 三次答对 |
|---|---|---|---|
| 低 | 1 天后 | 3 天后 | 7 天后 |
| 中 | 3 天后 | 7 天后 | 14 天后 |
| 高 | 7 天后 | 21 天后 | 45 天后 |

#### UI 描述

```
┌─────────────────────────────────────────────────────────┐
│  📝 主动回忆                              [今日目标]     │
│                                           12/20 题     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  第 8 / 20 题                                          │
│  ████████████████████░░░░░░░░  40%                     │
│                                                         │
│  ─────────────────────────────────────────────────     │
│                                                         │
│  泰勒公式中，e^x 在 x=0 处的展开式前三项是？             │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  A. 1 + x + x²                                 │   │
│  │  B. 1 + x + x²/2                               │   │
│  │  C. x + x²/2 + x³/6                            │   │
│  │  D. 1 + x² + x⁴                                │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  [   记得   ]  [  有点印象  ]  [  完全不记得  ]         │
│                                                         │
│  ─────────────────────────────────────────────────     │
│                                                         │
│  ⏱  回答正确！+0.8 掌握度              用时 12 秒      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

三个按钮的设计：不是判断对错，而是「主观感受」。用户凭直觉选择，记忆效果更好。

#### 交互环节

1. **进入练习**：从薄弱点引擎或日历打卡进入
2. **每日目标**：用户设定每日练习量（如 20 题），完成目标后显示鼓励语
3. **答题**：选择 A/B/C/D 或三个按钮（记得/模糊/忘记）
4. **即时反馈**：提交后立即显示对错，并解释为什么
5. **进度追踪**：实时显示今日进度，完成后给出总结报告
6. **复习提醒**：到点 WebSocket 推送通知

#### 验收标准

- [ ] 同一知识点，答对的间隔时间按算法自动延长
- [ ] 三个按钮（记得/模糊/忘记）对应不同的掌握度变化
- [ ] 每日目标完成后，显示「今日学习报告」
- [ ] 复习提醒在设定时间推送，不遗漏
- [ ] 练习数据自动写入档案

### P2-3：情绪识别与应对

#### 解决的问题

学习不是纯理性行为——情绪低落时效率极低。AI 通过学习行为数据识别用户情绪状态，在适当时机温柔干预。

#### 情绪识别信号

| 信号 | 情绪推断 |
|---|---|
| 深夜高频使用（> 凌晨 1 点） | 可能的焦虑/拖延 |
| 连续答错题后停止使用 3 天以上 | 可能的挫败感/放弃倾向 |
| 同一道题反复提问 | 可能的挫败 + 自我怀疑 |
| 练习量骤降至平时 30% 以下 | 可能的倦怠 |
| 番茄钟中断率 > 50% | 可能的注意力涣散/压力过大 |

#### UI 描述

```
┌─────────────────────────────────────────────────────────┐
│  💬 今日状态                                    [💭]    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  检测到：今晚已学习 2.5 小时，最后一题连续答错 3 次     │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  你还好吗？🌙                                    │   │
│  │                                                 │   │

│  │                                                 │   │

│  │  已经解锁了「泰勒展开」的专项练习，明天见！      │   │
│  │                                                 │   │
│  │  [好的，晚安]  [再坚持一下]  [聊聊刚才的题目]    │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

触发方式：WebSocket 推送弹窗，非侵入式。

#### 交互环节

1. **自动检测**：系统根据行为数据判断是否需要介入
2. **温柔推送**：非弹窗形式，以「状态卡片」出现在界面边缘

5. **数据脱敏**：情绪数据仅用于改善用户体验，不与他人共享

#### 验收标准

- [ ] 情绪检测基于行为数据，不要求用户主动输入情绪
- [ ] 推送频率每日不超过 2 次，不骚扰用户
- [ ] 用户可全局关闭情绪识别功能（设置中一键关闭）
- [ ] 情绪对话数据完全私密，仅用户可见

## 五、动画规范

所有动画使用 Framer Motion 实现，遵循以下规范：

### 5.1 通用过渡时长

| 类型 | 时长 | easing |
|---|---|---|
| 微交互（按钮点击、hover）| 150ms | `easeOut` |
| 展开/收起 | 250ms | `easeInOut` |
| 页面切换 | 300ms | `easeInOut` |
| 弹窗出现 | 200ms | `easeOut` |
| 流式文字出现 | 每个字符 30ms（逐字动画）|

### 5.2 固定动画

| 场景 | 动画 |
|---|---|
| 薄弱点列表新增卡片 | `slideUp` + `fadeIn`，从列表底部进入 |
| 里程碑达成 | 彩色粒子爆发效果 + 卡片放大 1.05 倍 |
| 每日目标完成 | 进度条变绿 + 打勾动效 |
| AI 消息气泡 | 从底部 `slideUp` + `fadeIn` |
| 情绪卡片弹出 | 从屏幕右下角 `slideIn`（不打断当前操作）|
| 成就解锁 | `scale 0→1.1→1` 弹性动画 |
| 热力图单元格 hover | `scale 1→1.2`，显示 tooltip |

### 5.3 SSE 流式文字

使用 `requestAnimationFrame` + 字符队列实现流畅打字效果：

```typescript
// 逐字显示，每个字符 30ms
// AI 思考时（首个 token 前），显示三点点动画
// Choices 类型消息，整句显示完后选项才出现
```

## 六、边界条件与限制

| 功能 | 限制 | 超出处理 |
|---|---|---|
| 即时问答 | 图片最大 10MB，支持 JPG/PNG/PDF | 超过提示「图片过大，请压缩后重试」|
| 即时问答 | 追问链最多 5 轮 | 第 5 轮后强制输出最终答案 |
| 即时问答 | 同时最多 1 个活跃 session | 新提问前必须结束或退出当前 session |
| 课件/教材 | PDF 最大 50MB | 提示「文件过大，请选择 50MB 以下的文件」|
| 课件/教材 | 单次最多上传 1 个文件 | 同时上传多个时只处理第一个 |
| 论文翻译 | PDF 最大 50MB，超过 50 页只解析前 50 页 | 提示用户可分段上传 |
| 主动回忆 | 每日练习上限 100 题 | 达到后提示「今日练习量已满」|
| 学习路径 | 同时最多 3 个活跃路径 | 新建前需暂停或完成一个 |
| 费曼学习 | 单次会话最多 20 轮追问 | 超限自动结束并生成报告 |
| 知识图谱 | 最多保存 20 个图谱 | 超限时提示用户删除旧图谱 |
| 档案导出 | 最多导出最近 1000 条历史记录 | 超出时提示「只导出最近 1000 条」|

## 九、技术债务清单

| 序号 | 债务项 | 说明 | 影响 | 优先级 |
|---|---|---|---|---|
| 1 | **引入 ChromaDB** | 当前无向量数据库，历史问答无法做语义检索 | 无法实现「你之前问过类似的」功能 | **P0** |
| 2 | **引入 Flask-SocketIO** | 当前无实时推送，档案更新需要刷新页面 | 用户体验割裂 | **P0** |
| 3 | **引入 APScheduler** | 无定时任务，复习提醒无法自动触发 | 间隔重复算法无法闭环 | **P0** |
| 4 | 图片公式识别 | 当前无手写公式识别能力（视觉模型） | 只能输入打印体题目 | P1 |
| 5 | 现有功能清理 | quotes、relaxation 等功能前端已删但后端 blueprint 残留 | 技术债积累 | P2 |
| 6 | 数据库分库 | SQLite 不适合高并发写入 | 未来用户量增长后需迁移 PostgreSQL | P3 |
