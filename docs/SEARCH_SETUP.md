# 搜索功能配置指南

## 概述

系统已集成 Tavily 搜索 API，可以在以下场景自动获取最新信息：
- **即时问答**：当用户询问最新动态、新闻、趋势时
- **学习路径规划**：当主题涉及快速发展的领域时

## 配置步骤

### 1. 获取 Tavily API Key

1. 访问 [Tavily](https://tavily.com)
2. 注册账号（支持 Google/GitHub 登录）
3. 在控制台获取 API Key
4. 免费额度：1000 次搜索/月

### 2. 配置环境变量

在 `backend/.env` 文件中添加：

```bash
TAVILY_API_KEY=tvly-xxxxxxxxxxxxxxxxxxxxxx
```

### 3. 重启后端服务

```bash
cd backend
python3 app.py
```

## 工作原理

### 自动触发条件

搜索功能会在以下情况自动触发：

1. **关键词触发**：用户输入包含以下关键词时
   - 时间相关：最新、最近、现在、当前、今年、2025、2026
   - 搜索相关：搜索、查找、查询、找一下
   - 动态相关：新闻、动态、趋势、发展

2. **学习路径规划**：当主题名称包含上述关键词时

### 搜索结果处理

- 每次搜索返回 3-5 条最相关的结果
- 结果会自动整合到 AI 的上下文中
- AI 会基于搜索结果和自身知识综合回答

## 使用示例

### 即时问答

**触发搜索的问题：**
```
用户：最新的机器学习趋势是什么？
系统：[自动搜索] → 返回包含最新信息的回答

用户：2026年人工智能的发展方向
系统：[自动搜索] → 返回最新趋势分析

用户：搜索一下 Transformer 架构的最新改进
系统：[自动搜索] → 返回最新研究进展
```

**不触发搜索的问题：**
```
用户：什么是机器学习？
系统：[使用已有知识] → 返回基础概念解释

用户：解释一下梯度下降
系统：[使用已有知识] → 返回算法原理
```

### 学习路径规划

**触发搜索的主题：**
```
主题：2026年前端开发最新技术栈
→ 自动搜索最新前端趋势，生成包含最新技术的学习路径

主题：当前最流行的深度学习框架
→ 自动搜索最新框架对比，生成针对性学习路径
```

## 无 API Key 时的行为

如果未配置 `TAVILY_API_KEY`：
- 搜索功能会静默失败（不报错）
- AI 仍会基于自身知识回答问题
- 不影响其他功能的正常使用

## 成本估算

- **免费额度**：1000 次搜索/月
- **触发频率**：约 5-10% 的问题会触发搜索
- **预估使用**：中等活跃度用户每月约 50-100 次搜索

## 故障排查

### 搜索不工作

1. 检查 API Key 是否正确配置
2. 检查网络连接
3. 查看后端日志是否有错误

### 搜索结果不准确

- Tavily 会自动优化搜索查询
- 如果结果不理想，可以调整 `search_service.py` 中的 `max_results` 参数

## 扩展其他搜索服务

如果想使用其他搜索服务（如 Serper、Bing），可以修改 `backend/services/search_service.py`：

```python
def search_web(query: str, max_results: int = 5) -> list[dict[str, Any]]:
    # 替换为其他搜索 API 的实现
    pass
```
