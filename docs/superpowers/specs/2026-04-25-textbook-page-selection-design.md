# 教材页选中附件设计

## 目标

让用户在教材对话页右侧直接点击教材页面，切换页面选中状态。被选中的页面以高亮方式展示，并在提问时作为优先附件页发送给 AI；支持多选和取消选中。

## 交互

- 右侧教材区域新增 `选页模式` 开关。
- 开启后，教材页改为应用内逐页渲染图片列表。
- 点击某一页会切换该页的选中状态。
- 选中的页展示描边和浅色高亮。
- 左侧输入区上方显示已选页摘要，并支持一键清空。
- 发送消息时：
  - 有手动选页：只发送这些选中页。
  - 无手动选页：回退到系统默认页范围。

## 技术方案

- 后端新增教材单页图片接口，按教材 ID 和页码返回 PNG。
- 前端 PDF 预览从 `iframe` 切到逐页图片列表。
- 前端维护 `selectedPages` 状态，并把它带到 `/api/v1/textbook/<id>/query`。
- 后端查询逻辑优先使用 `selectedPages` 渲染图片并发给视觉模型。

## 风险与约束

- 应用内逐页图片渲染会失去浏览器原生 PDF 工具栏，但换来可控的页级交互。
- 多页同时发送会增加请求体大小，因此手动选页必须优先覆盖默认范围。
- 文本型教材仍保留原有文本检索兜底。
